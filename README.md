# BloodMoon
Это простейший календарь для отслеживания женский циклов.
Писался за 2 суток, как бесплатная простая замена платным вариантам.

При нажатии на дату(красный), через Х дней создается прогнозируемое событие(розовое).
Для кастомной настройки периодов под себя, редактируйте структуру CycleSettings.
